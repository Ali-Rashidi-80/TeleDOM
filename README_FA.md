## 💡 به زبان خیلی ساده، TeleDOM چیه؟

تا حالا شده به **Claude** یا **Cursor** بگی:
> *«برو فلان دکمه سایتم رو درست کن»* یا *«ببین چرا این فرم کار نمیکنه»*؟

مشکل اینجاست که هوش مصنوعی در حالت عادی **کور و نابیناست!** یعنی مرورگر واقعی شما رو نمی‌بینه، نمی‌دونه صفحه چطور لود شده، کدهای CSS چطور روی هم افتادن و وقتی کاربر روی دکمه کلیک می‌کنه چه اتفاقی توی صفحه می‌افته.

**TeleDOM مثل یک عینک هوشمند و جعبه‌ابزار فوق‌پیشرفته روی مرورگر شما نصب میشه.**
این ابزار تمام اتفاقات صفحه وب (کلیک‌ها، تغییرات لحظه‌ای، ارورها و وضعیت شبکه) رو با سرعت مافوق صوت ثبت می‌کنه و در قالب **۲۰۶ ابزار آماده** در اختیار هوش مصنوعی میذاره تا بتونه درست مثل یک برنامه‌نویس حرفه‌ای، سایت شما رو ببینه، تحلیل کنه و باگ‌هاش رو درجا رفع کنه! 🚀

## ❓ مشکل بزرگ چی بود؟ (چرا قبلاً کار سخت بود؟)

1. **باگ‌های غیب‌شونده (Disappearing Bugs):** المان‌هایی که توی صفحه یه لحظه میان و سریع غیب میشن و تا کنسول رو باز می‌کنی اثری ازشون نیست!
2. **کدهای اشتباه هوش مصنوعی:** چون هوش مصنوعی فقط یه متن از کد رو می‌دید و ظاهر واقعی وب‌سایت رو نمی‌دید، نصف کدهایی که پیشنهاد می‌داد اصلاً کار نمی‌کرد.
3. **روباتیک بودن ابزارهای قبلی:** ابزارهای قدیمی مثل ربات‌های ناشی کلیک می‌کردن و سایت‌ها سریع اونا رو بلاک می‌کردن.

## ✨ قابلیت‌های شگفت‌انگیز (چرا همه عاشقش میشن؟)

### ⏳ ۱. ماشین زمان برای صفحات وب (Time-Travel Debugging)
فرض کن روی دکمه «خرید» کلیک کردی و صفحه سفید شد یا ارور داد. با TeleDOM هوش مصنوعی می‌تونه مثل فیلم، وضعیت صفحه رو **میلی‌ثانیه به میلی‌ثانیه به عقب برگردونه** و بهت بگه:
> *«دقیقاً در میلی‌ثانیه ۴۵۰، وقتی تابع X اجرا شد، این باگ به وجود اومد!»*

### 🎯 ۲. انتخاب هر کجای صفحه فقط با موس (Live Element Picker)
دیگه لازم نیست Inspect Element باز کنی و کدهای طولانی رو کپی کنی!
فقط کافیه کلید‌های `Ctrl + Shift` رو نگه داری و روی هر بخش از سایتت کلیک کنی؛ TeleDOM همه اطلاعات اون المان، استایل‌ها، رنگ‌ها و خطاش رو دسته‌بندی می‌کنه و میده به هوش مصنوعی تا درجا برات درستش کنه.

### 🖱️ ۳. رفتار و تعامل کاملاً شبیه انسان (Human-like Interaction)
این ابزار موس رو کاملاً ارگانیک حرکت میده، با تاخیرهای طبیعی کلیک می‌کنه، مثل آدم واقعی تایپ می‌کنه و اسکرول نرم انجام میده؛ بنابراین هیچ سایتی نمی‌تونه تشخیص بده که یک ربات یا هوش مصنوعی پشت صفحه است!

### 🧠 ۴. شکارچی نشتی حافظه (Memory Leak Hunter)
اگه سایت یا پروژه‌ت بعد از مدتی سنگین و کند میشه، TeleDOM به هوش مصنوعی اجازه میده حافظه رم مرورگر (Heap Snapshot) رو بررسی کنه و بگه کدوم کدها دارن رم سیستم رو بیهوده مصرف می‌کنن.

### 🔒 ۵. صددرصد امن و شخصی (Local-First)
تمام داده‌ها **روی کامپیوتر خودت** پردازش میشن و حتی یک بایت اطلاعات هم به هیچ سرور ناشناس خارجی ارسال نمیشه. کاملاً امن، منبع‌باز و رایگان.

## 🚀 آموزش نصب و استفاده در ۲ دقیقه

### مرحله ۱: روشن کردن سرور
ترمینال رو باز کن و خیلی ساده دستور زیر رو بزن:
```bash
npx teledom
```
*(سرور به‌صورت خودکار در پشت‌صحنه روشن میشه و آماده ارتباط با هوش مصنوعی و افزونه است)*

### مرحله ۲: نصب افزونه روی کروم (فقط یکبار)
1. مرورگر **Google Chrome** رو باز کن و برو به آدرس `chrome://extensions`.
2. تیک **Developer mode** (حالت برنامه‌نویس) رو در گوشه بالا سمت راست روشن کن.
3. دکمه **Load unpacked** رو بزن و پوشه `chrome-extension/dist` داخل این پروژه رو انتخاب کن.
4. تموم شد! آیکون افزونه به مرورگرت اضافه شد.

## 🤝 سازگار با ابزارهای محبوب شما

این پلتفرم از استاندارد جهانی **Model Context Protocol (MCP)** پشتیبانی می‌کنه، یعنی کافیه کانفیگ زیر رو به نرم‌افزار هوش مصنوعی مورد علاقت اضافه کنی:

```json
{
  "mcpServers": {
    "teledom": {
      "command": "npx",
      "args": ["-y", "teledom"]
    }
  }
}
```

| نرم‌افزار / دستیار | وضعیت پشتیبانی | نحوه استفاده |
| :--- | :---: | :--- |
| **Claude Desktop** | ✅ کاملاً سازگار | اضافه کردن کانفیگ به `claude_desktop_config.json` |
| **Claude Code (ترمینال)** | ✅ کاملاً سازگار | اجرای مستقیم در پروژه‌ها |
| **Cursor / Windsurf** | ✅ کاملاً سازگار | فعال در بخش MCP Settings |
| **Google Antigravity IDE** | ✅ کاملاً سازگار | شناسایی خودکار در محیط پروژه |

## 🛠️ دسته‌بندی ۲۰۶ ابزار به زبان ساده

برای اینکه بدونی این پلتفرم چقدر کامله، ابزارهاش به چند دسته اصلی تقسیم میشن:

1. **ابزارهای چشم مرورگر (DOM & Visual):** دیدن ساختار صفحه، اسکرین‌شات از المان‌های خاص، مقایسه ظاهر صفحه قبل و بعد از تغییرات.
2. **ابزارهای دست مرورگر (Interactions):** کلیک نرم، تایپ متن، درگ اند دراپ، اسکرول و فشردن کلیدهای میانبر.
3. **ابزارهای ماشین زمان (Time-Travel):** عقب و جلو بردن صفحه، پیدا کردن المان‌های ناپدیدشده و علت غیب شدنشون.
4. **ابزارهای پیشرفته دولوپر (DevTools Fusion - 54 ابزار):** مانیتورینگ درخواست‌های اینترنت (Network)، لاگ‌های کنسول و بررسی مصرف رم.
5. **ابزارهای کالبدشکافی عمیق (Forensics - 31 ابزار):** تحلیل فونت‌ها، تداخل رنگ‌ها و Z-index، دسترسی‌پذیری و باگ‌های انیمیشن.
