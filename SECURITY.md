# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.1.x   | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **TeleDOM**, please do NOT open a public issue. Instead, please report it via email to:

`contact@irmaho.dev`

Please include:
- A description of the vulnerability and its potential impact.
- Clear steps or a minimal proof-of-concept (PoC) to reproduce the issue.
- Your proposed remediation if available.

We will review and respond to reports within 48 hours.
