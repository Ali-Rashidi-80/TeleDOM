# 🛠️ بسته کامل توسعه اکستنشن چت‌جی‌پی‌تی (Chrome Extension UI Injection Kit)

این بسته شامل تمامی ابزارها، سلکتورها و کدهای نمونه برای ساخت یک اکستنشن کامل و دستکاری تمام بخش‌های رابط کاربری ChatGPT می‌باشد.

---

## 🚀 محتویات بسته:
1. `chatgpt-selectors.json`: بانک جامع سلکتورهای CSS دسته‌بندی‌شده برای تمامی کامپوننت‌ها
2. `sample-content-injector.js`: کد استاندارد کانتنت‌اسکریپت با `MutationObserver` و مدیریت ریدایرکت‌های SPA
3. پوشه‌های `00` تا `12`: مستندات اختصاصی، اسکرین‌شات و کدهای HTML هر بخش

---

## ⚡ نکات حیاتی برای جلوگیری از کرش کردن ری‌اکت (React Hydration & Crash Prevention):
1. **هرگز فرزندان مستقیم گره‌های رندر مارک‌داون را حذف نکنید**: به جای حذف، از `display: none` استفاده کنید.
2. **برای اینجکت کردن فرم‌ها و دکمه‌ها**: از `insertAdjacentElement('beforebegin', ...)` یا `insertAdjacentElement('afterend', ...)` در لایه‌های بیرونی فرم کامپوزر استفاده کنید تا تداخلی با State ری‌اکت پیدا نکند.
3. **ثبت وضعیت تزریق با دیتا-اتریبیوت**: با ست کردن `el.dataset.injected = 'true'` از دوباره‌سازی المان‌ها در MutationObserver جلوگیری کنید.
